# cloud-security-engineer-journey
50-day hands-on Cloud Security Engineering programme

## Technologies

- AWS
- Terraform
- IAM and STS
- VPC and network security
- CloudTrail and detection engineering
- Linux
- Python and Bash
- Docker and Kubernetes
- DevSecOps and CI/CD
- CSPM and compliance
- AI implementation and AI-agent security

## Daily missions

| Day | Topic |
|---|---|
| 01 | Terraform Three-Tier Network Security |

Each mission contains commented source files, a technical
README, a controlled failure, remediation, verification,
cleanup and interview questions.

## Capstones after Day 50

1. Cloud Security Posture and IAM Auditor
2. Cloud Detection and Incident Response Platform
3. Enterprise DevSecOps Security Pipeline
4. Guardrailed AI Cloud Security Analyst

## Engineering principles

- Least privilege
- Infrastructure as Code
- Secure credential handling
- Reviewed infrastructure changes
- Evidence-based investigation
- Repeatable deployments
- Documented remediation
